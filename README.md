# AiFRAHAT

An open-source portfolio and interactive research lab for Ahmed Frahat.

The site presents AI research interests through working browser experiments rather than static claims. It is bilingual, responsive, accessible, and deploys directly to GitHub Pages without a build step.

## Live site

[aifrahat.com](https://aifrahat.com)

## Experience

- Animated Canvas 2D research graph with pointer interaction and reduced-motion support.
- Arabic and English interface with correct RTL/LTR switching.
- Interactive RAG tuning simulation with quality, recall, precision, latency, and context feedback.
- Agent-trace timeline that exposes each reasoning stage as a reviewable sequence.
- Searchable live preview for the [iMHOTiP](https://imhotip.com) technology dictionary.
- Command palette, theme control, mobile navigation, animated counters, and scroll reveals.
- Semantic HTML, keyboard support, responsive layout, SEO metadata, manifest, sitemap, and favicon.

## Stack

- Semantic HTML5
- Modern CSS with custom properties, logical properties, responsive grids, and reduced-motion handling
- Dependency-free JavaScript
- Canvas 2D and ResizeObserver
- IntersectionObserver and Dialog API
- GitHub Pages with the custom domain in `CNAME`

## Run locally

Open `index.html` directly in a browser. No installation or build command is required.
